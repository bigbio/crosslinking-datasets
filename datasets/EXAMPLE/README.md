# EXAMPLE Dataset

This is an example dataset demonstrating the SDRF file structure for crosslinking experiments.

**Note**: This is a template example for demonstration purposes. Replace this with actual ProteomeXchange datasets.

## Dataset Information

- **Accession**: EXAMPLE (placeholder)
- **Title**: Example Crosslinking Experiment
- **Organism**: Homo sapiens (Human)
- **Cell Type**: HEK293T cells
- **Crosslinker**: DSS (Disuccinimidyl suberate)
- **Instrument**: Orbitrap Fusion Lumos
- **Biological Replicates**: 3

## Experiment Description

This example demonstrates a typical crosslinking proteomics experiment with:
- Three biological replicates
- DSS crosslinker
- Trypsin digestion
- Oxidation as a variable modification
- Label-free quantification approach

## SDRF File

The `EXAMPLE.sdrf.tsv` file contains:
- Sample information (organism, cell type, disease state)
- Replicate information (biological and technical)
- Instrument details
- Modification parameters including crosslinker
- Data file names and URIs

## Usage

This example can be used as a reference when creating SDRF files for actual crosslinking datasets. The structure and format shown here should be followed for all datasets added to this repository.

For actual datasets, replace:
- `EXAMPLE` with the ProteomeXchange accession (e.g., `PXD012345`)
- Sample names with actual sample identifiers
- File names with real data file names
- URIs with actual data file locations
- All metadata with accurate experimental information
